# Hero Editorial de MUBATO

# Propósito

El Hero es la puerta de entrada a la historia de un proyecto.

No describe un espacio.

No presenta un mobiliario.

No resume una remodelación.

El Hero invita al lector a imaginar una nueva manera de habitar.

Debe despertar curiosidad.

Debe transmitir serenidad.

Debe abrir la puerta a la historia que viene después.

---

# Qué debe lograr un Hero

Un Hero debe hacer que el lector:

Imagine el espacio.

Perciba una emoción.

Comprenda que ocurrió una transformación.

Quiera continuar leyendo.

Nunca debe sentirse como un anuncio publicitario.

Nunca debe parecer un catálogo.

Nunca debe sonar como un texto generado automáticamente.

---

# El protagonista

El protagonista nunca es MUBATO.

El protagonista nunca es el mobiliario.

El protagonista siempre es la experiencia de quien habita el espacio.

El Hero debe hablar de personas antes que de objetos.

Debe hablar de bienestar antes que de materiales.

Debe hablar de transformación antes que de diseño.

---

# Cómo comienza un Hero

El Hero nunca comienza describiendo un espacio.

Incorrecto:

"Este apartamento fue remodelado..."

Incorrecto:

"Esta cocina fue diseñada..."

Incorrecto:

"El proyecto consistió en..."

Preferimos comenzar hablando de una experiencia.

De una sensación.

De una manera de vivir.

---

# Cómo evoluciona

Después de despertar una emoción...

el Hero muestra cómo el diseño hace posible esa experiencia.

Nunca explica el proceso técnico.

Nunca enumera decisiones de diseño.

Nunca describe acabados.

Cada frase debe acercar al lector a una mejor manera de habitar.

---

# Cómo termina

El Hero no termina vendiendo.

No termina invitando a contactar a MUBATO.

No termina con una conclusión.

Debe dejar una sensación abierta.

El lector debe querer conocer la historia completa del proyecto.

---

# Extensión

Entre 60 y 100 palabras.

Preferiblemente un solo bloque de texto.

No utilizar títulos.

No escribir el nombre del proyecto.

No utilizar viñetas.

---

# Qué debe evitar

No describir muebles.

No enumerar materiales.

No mencionar medidas.

No hablar de presupuesto.

No hablar de marcas.

No exagerar.

No utilizar clichés.

No utilizar frases hechas.

No utilizar lenguaje publicitario.

No utilizar superlativos.

No utilizar llamados a la acción.

---

# Qué debe transmitir

Calma.

Bienestar.

Equilibrio.

Armonía.

Luz.

Transformación.

Permanencia.

Vida cotidiana.

Naturalidad.

---

# Estructura sugerida

1.

Comienza con una experiencia humana.

↓

2.

Relaciona esa experiencia con el espacio.

↓

3.

Muestra cómo el diseño hace posible esa transformación.

↓

4.

Finaliza dejando una sensación.

No una conclusión.

---

# Ejemplo incorrecto

Diseñamos una espectacular cocina con acabados premium y una iluminación moderna que transforma completamente el espacio.

¿Por qué está mal?

Habla de diseño.

Habla de materiales.

Habla de adjetivos.

No habla de personas.

Podría pertenecer a cualquier estudio de interiorismo.

---

# Ejemplo correcto

Hay espacios que cambian la rutina sin hacer ruido. Cuando la luz, los materiales y cada decisión encuentran equilibrio, la vida cotidiana comienza a sentirse diferente. Ese es el verdadero propósito del diseño: crear lugares donde permanecer resulte tan natural como habitar.

¿Por qué funciona?

Habla de una experiencia.

No exagera.

No vende.

No describe un catálogo.

Invita a seguir leyendo.

---

# Lista de verificación

Antes de aprobar un Hero, verifica:

□ ¿Habla de personas antes que de objetos?

□ ¿Invita a imaginar el espacio?

□ ¿Transmite bienestar?

□ ¿Evita clichés?

□ ¿Evita lenguaje comercial?

□ ¿Podría pertenecer únicamente a MUBATO?

□ ¿Despierta curiosidad?

Si alguna respuesta es "no"...

el Hero debe volver a escribirse.

---

# Principio editorial

El Hero no existe para describir un proyecto.

Existe para hacer que el lector quiera habitarlo antes de conocerlo.
